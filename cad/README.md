# CAD

<https://cad.onshape.com/documents/fccfa08dfedefe67cfdb683e/w/4726c041ddb97f340fe57a69/e/d62cb220f0c6f90c2b79ed01>

| Path        | Content                                                    |
| :---------- | :--------------------------------------------------------- |
| `3d-print/` | Print-ready exports of the 3D-printed parts.               |
