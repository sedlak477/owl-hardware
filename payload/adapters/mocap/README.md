# Motion-capture marker adapter

Carries five optical motion-capture markers on arms of different lengths, so the motion-capture system can track the OWL's rotation as a rigid body.
The arrangement is asymmetric, so every orientation is unambiguous.

Glue the markers onto the round pads at the ends of the arms.
