# nRF54L15 DK adapter

Holds a Nordic [nRF54L15 DK](https://www.nordicsemi.com/Products/Development-hardware/nRF54L15-DK) upright on the OWL.

Fix the DK to the plate with M2.5 screws. Nylon screws are recommended.
