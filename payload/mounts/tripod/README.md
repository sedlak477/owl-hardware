# Tripod mount

Screws onto a camera tripod and provides the same payload connector as the OWL, so any adapter snaps into it just like into an OWL.
Use it for devices that stay fixed in a setup, such as anchors or reference nodes, with the same adapters and mounting geometry as the rotating ones.

It uses the same 1/4" heat insert as the OWL's tripod adapter (see the [assembly instructions](../../../docs/Assembly%20instructions.md)).
