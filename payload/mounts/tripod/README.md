# Tripod mount

Screws onto a camera tripod and provides the same connector base as the OWL, so any adapter locks onto it just like onto an OWL.
Use it for devices that stay fixed in a setup, such as anchors or reference nodes, with the same adapters and mounting geometry as the rotating ones.

It has two printed parts: a body with a 1/4" heat insert for the tripod screw, and the connector base on top.
Print both as laid out in the STEP (body bottom down, base lugs up), no supports needed.

1. Press the 1/4" heat insert into the bottom of the body. It is the same insert as in the OWL's tripod adapter (see the [assembly instructions](../../../docs/Assembly%20instructions.md)).
2. Put the base on the body, lugs up, with its screw holes over the holes in the body.
3. Screw the base on with three M1.6×8 screws. They cut their own thread in the body.
